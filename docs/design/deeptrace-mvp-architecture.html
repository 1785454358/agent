关键设计判断： 第一版采用“一个 Planner + 并行 Researcher + 一个 Verifier”的受控多智能体结构。每个 Agent 都有明确输入输出，不让多个角色自由聊天；这样更容易测试、恢复、限制成本，也更符合工程化 Agent 的面试重点。
