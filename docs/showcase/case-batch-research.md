## 实际研究操作

1. 将问题拆为三个研究方向，保留原始问题、时间范围与执行约束。
2. 程序按计划检索并选择来源，去重后批量抓取，复用已授权原文。
3. 读取证据片段，保留内容版本、哈希和正文坐标。
4. 每个分支集中整理一次，由全局核验检查固定需求与原文支持。
5. 生成中文回答，校验引用并交付来源；存在缺口时按缺口有限补查。
