# 方案先行研究：实施与真实验收

2026-11-15。用户确认优化“选定方案—针对性取证—检查方案一致性”。本轮实现该链路，复用既有 Planner、取证循环、Writer 与最终审查；没有新增常驻 Agent、提供商或成功路径的模型调用阶段。

**结论：主线机制已实施；同材料复核中，北京路线顺序得到修正，预算表及正文引用改由宿主计算。完整事实核实和全部语义一致性仍未全面合格。** 请勿把测试通过、算术正确或检查项齐全理解成模型对价格、单位和来源身份的判断正确。

## 实现如何改变研究链路

1. 同一次 Planner 输出 `DeliveryPlan`，明确暂定主线、假设、交付步骤、需求对应的检索词和跨步骤检查。它不替代原始问题，也不获得用户授权或事实资格。
2. controller 根据有效需求查询分配分支，保证每个已声明事实需求有实际搜索种子；最多原配置任务数，每分支最多2条，所有种子写入可恢复的执行计划。非法引用局部降级，旧数据无该字段时继续原路径。
3. 方案贯穿取证简报、缺口补查、研究结果、Writer和原文审查。范围审查、需求重编号、checkpoint与同线程新任务均有回归，旧模式可传递方案。
4. 最终审查返回每项检查的ID、passed/unresolved及依据。宿主拒绝漏项、重项和伪造编号，unresolved保持partial；关闭审查也不能把方案当作已检查完成。passed依然是模型判断。
5. 修复成功但有限窗口的评估抹掉旧证据的问题：旧发现只在原文版本/哈希/引用仍有效时保留，不复用旧coverage；原文变更与本轮明确拒绝仍会剔除。跨轮模型ID复用不覆盖旧事实。
6. controller把合法来源拒绝交给宿主归一，再补查缺口，不因同批材料再求一次来源判定消耗预算。结构错误和无依据的来源限制仍可修复，legacy默认策略保持。
7. 方案任务使用精简审查策略；预算由模型返回结构化预算行，宿主计算数量/分摊和上下限、渲染表格及总额引用，未知费用不按零计。没有新增模型调用阶段；正式实现未保留自由Markdown算术解析的原型。

两轮均在首次搜索前产生方案及实际检索分配；最终检查没有格式重试，均为一次成稿、一次审查。所有最终一致性检查的编号完整。没有改变20次/100,000输入token上限。

北京保留10条收集证据、6条接受发现，最终引用7个URL。回答延续故宫/天安门/景山、慕田峪、天坛/前门主线，列明单双人分摊、住宿区域、费用及预约；交通部分开始单列长城公交或直通车，不再只拿地铁40元覆盖全部往返。5项一致性检查中1项unresolved，系统事实覆盖3/6；这些均为模型与宿主的结构性结果，不是人工准确率。

## 完整取证试验的人工检查（后续修复的依据）

- **北京预算仍不合格。** 表中低端400+62+72+300+300=1134，高端600+62+120+450+500=1732，回答却写约1130—1830。更关键的是合计排除了未核实的故宫/天坛门票，首段仍据此说低于2000元。审查将费用检查c3标为passed，说明枚举检查项没有消除模型误判。
- **北京路线仍有回走。** 故宫出口之后再去天安门、然后回景山，虽然引用了“南向北”的规则，却没有据此正确调整游览顺序；预约要求也存在第三方或时效不足的材料。住宿、餐饮仍缺对应日期下的价格依据。
- **监控方案仍有依赖假设。** 用户只明确已有服务器，答案把已有SMTP邮箱也作为零增量假设；若该假设不成立，应另选通知渠道并重算，不能直接保证0元。同时绑定127.0.0.1后团队远程访问仍依赖尚未具体配置的安全通道，30天历史尚需验证。
- **来源身份仍可能误判。** 某些教程或非项目官网可能被模型称为“官方”；该判断没有因新方案对象而自动变可靠。跨轮保留证据仅证明版本与引用仍匹配，不证明一次语义判断永远正确。
- 方案抽取仍可能漏掉某个用户维度，或选择过多景点；宿主保证“已声明需求都有查询”，不保证模型声明已经完整覆盖自然语言请求。两类各少量样本不能证明通用能力或达到市场产品水平。

因此本轮可以确认的是：方案已成为贯穿流程的数据，取证可以围绕它分配，未解决检查可以阻止完整完成，证据可以增量保留；不能确认的是答案在算术、路线和所有事实上的全面正确。后续应针对这些实际失败样本改进决策与检查，避免只增加检查条目或把partial改成completed。

### 最终仍需改进

- 算术保证针对已提交的结构化预算行及总额引用；宿主不能证明价格或单位选择、数量、是否漏项本身正确，也不自动换算币种与月/年口径。
- 北京住宿、餐饮和部分票价仍依赖预算假设；首段的约数与其他自然语言取舍仍是模型表达。单人替代口径没有完整单列表格时，不保留模型自由书写的重复合计，只要求按相应分项核算。
- 未知或可选费用会触发未计价提示，可能比用户实际需要更保守；仍需更准确地区分选中主线的必要项与未启用选项。
- 路线、交通覆盖、来源是否官方、教程是否适用于当前版本仍需语义核查；passed不是宿主对这些事实的证明。
- 同材料复核不是新的全程研究测试，也不能证明多题稳定性或与市场产品的排名。
