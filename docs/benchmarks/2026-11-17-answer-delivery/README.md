# 回答交付修复验证

本轮修复了“已有合格原文，但没有 accepted findings 就跳过写作”的缺陷；没有改写历史运行状态，也没有将部分完成直接改为成功。

## 改动

1. 来源与结论分别准入。只有合格且 ACTIVE 的授权原文进入写作，只有 accepted findings 进入已核验结论；空 accepted 集合仍可根据原文解释证据范围、未知条件与无法推出的结论。
2. 关闭额外上下文扩展时，无 accepted supports 的来源仍有基本原文窗口；全局 Token 预算与引用校验继续生效。
3. 最终审查坏格式、正文无法解析或生成预算拒绝时，可以保留写作实际可见且已检查来源坐标的原文引用，不仅返回标题。不把无效草稿发布为结论，状态仍为 partial。
4. 预算正则仅处理紧随合计标签的显式货币断言，不跨越任意文字误删预算口径、升级建议与餐次数量；宿主仍计算结构化金额合计。
