# 同题产品对比方法

日期：2026-10-24。提示原文在 `prompt.txt`。问题选自本项目上一轮实际研究主题，增加统一的输出要求；适合检查概念对比和证据边界，不代表所有研究场景。

各产品新会话、相同中文输入、每个模式一次运行，不注入本项目答案、参考答案或固定资料。保留首个完整回答、错误或登录阻挡，不挑选多次结果中的最佳答案。联网由各产品自行决定，是否实际使用必须单独记录。记录实际模式与登录状态；匿名普通模式不能代表收费模式或深度研究的上限。

预先确定的核对项目：

1. 区分执行状态 checkpoint 与应用数据 Store，不把 Store 当执行恢复器。
2. 说明 thread_id、命名空间和跨线程共享的边界，不把线程隔离当权限系统。
3. 说明重启后的行为取决于持久化后端，不能把内存实现说成重启后保留。
4. 说明 interrupt 恢复的条件、从节点开头重新执行以及副作用幂等性。
5. 提供可操作的选型建议，并区分事实、推断、未知项。
6. 按要求结论在前、表格比较；来源能定位到可支持具体结论的官方材料。

先保留原始输出，再依据官方原文核对关键断言。引用数量、篇幅不等同于正确性，不用本项目模型为自己和竞品打综合分。比较表使用具体观察与反例，缺失或无法确认明确记录。

本项目通过当前生产 application service 运行，Workflow、新线程、默认模型和预算；不复用上一轮研究材料，不为本题改代码或提示词。模型、调用数、实际来源、耗时和 partial 状态另行记录。竞品如果没有可靠的端到端计时则不编造速度排名。

项目运行环境使用 local、空 MySQL/Redis DSN 和 lexical 记忆检索，以隔离外部持久化基础设施；这几项实验环境设置不等同于所有线上部署配置。研究、生成、审查与共享预算仍走生产实现。
