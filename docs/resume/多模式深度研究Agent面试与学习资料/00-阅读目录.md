# 多模式深度研究 Agent 面试与学习资料

这套材料已经按学习任务拆开。第一次阅读按编号顺序进行，面试前复习时直接进入对应专题。

## 阅读顺序

1. [项目介绍与表达](01-项目介绍与表达.md) 先学会在 90 秒和 3 分钟内讲清项目。
2. [Harness 总体架构](02-Harness总体架构.md) 用六张 Mermaid 图建立完整结构。
3. [项目目录与源码导读](03-项目目录与源码导读.md) 把架构映射到真实文件、类和函数。
4. [Harness 核心机制](04-Harness核心机制.md) 深入 State、Memory、Gateway、Evidence 和恢复。
5. [面试高频问题与答案](05-面试高频问题与答案.md) 练习常见问题与压力追问。
6. [源码学习与自测](06-源码学习与自测.md) 按四轮顺序读代码并脱稿回答。
7. [作品展示制作指南](../作品展示制作指南.md) 准备 GitHub 仓库、90 秒演示和静态架构图。

## 学习标准

给出一个真实请求后，能够指出它经过哪些模块、改变哪些状态、调用哪些函数、数据保存在哪里，崩溃后怎样继续。

## 一句话项目定义

这是一个以 Agent Harness 统一运行治理的多模式深度研究 Agent。三种 LangGraph 研究策略共享模型、工具、证据、记忆、预算和恢复机制，在不同研究路径下都返回可验证的统一结果。

## 快速入口

- 明天就要面试，先读 01、02、05。
- 需要真正理解代码，按 01 到 06 完整阅读。
- 面试官追问可靠性，读 04 中的 Checkpoint、Ledger、预算和租约。
- 面试官追问 Multi-Agent，读 02 的策略图和 05 的第 20 至 22 题。
