推荐顺序：项目深度拆解 → 学习与面试路线 → 源码学习指南 → 实现差距与完善清单 → 面试手册 → DeepResearch 核心差异面试与学习手册。只准备投递时，可以直接阅读简历项目材料。

材料遵守三条规则：

- “已实现”必须能由当前源码或测试验证。
- 真实 Provider 和外部服务没有运行证据时，只描述接口与离线验证。
- 认证租户隔离、通用审批、完整 Prompt Injection 防护、精确 Token 计费和在线评测属于演进方向。
