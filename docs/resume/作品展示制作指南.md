# DeepResearch 作品展示指南

这个展示包面向 Agent 开发工程师岗位，只证明三件事：项目能运行、Harness 边界清楚、可靠性规则可以验证。仓库首页、演示页面和面试讲解使用同一组术语。

## 已准备的展示材料

- 仓库首页：[根 README](../../README.md)
- 无 Key 演示：`cd frontend && npm run showcase`
- 工作台截图：[deepresearch-workbench.png](../assets/deepresearch-workbench.png)
- 简化架构图：[deepresearch-harness.svg](../assets/deepresearch-harness.svg)
- 完整架构说明：[agent-harness.md](../architecture/agent-harness.md)

Showcase Mode 使用固定夹具数据，不依赖后端、API Key 或网络。页面明确显示 `SHOWCASE DATA`，可以切换 Workflow、Plan-and-Execute 和 Multi-Agent，并展示问题、执行轨迹、答案、来源和 Runtime invariants。

## 90 秒演示脚本

| 时间 | 画面 | 讲解重点 |
| --- | --- | --- |
| 0–12 秒 | README 首屏和架构图 | DeepResearch 的重点是统一 Agent Harness，而不是某一种研究策略 |
| 12–28 秒 | 启动 Showcase，选择 Plan-and-Execute | Session Graph 管理会话和路由，策略进入同一个 Shared Agent Loop |
| 28–48 秒 | 执行轨迹 | ModelGateway 和 ToolGateway 是唯一外部调用边界；无依赖工具可有界并行 |
| 48–65 秒 | 最终答案和来源 | Evidence Store 保存正文与溯源，State 只携带受限内容或 Evidence ID |
| 65–80 秒 | Runtime invariants | 模型信封、ToolMessage 配对、Gateway 边界、AgentOutcome 和恢复后不变量 |
| 80–90 秒 | 测试命令 | 确定性测试与真实服务验收分开，不夸大未验证能力 |

口播参考：

> DeepResearch 基于 LangGraph 构建。顶层 Session Graph 管理会话、记忆和策略路由，Workflow、Plan-and-Execute、Multi-Agent 共享一个模型驱动的 Agent Loop。每次模型调用都经过 ModelGateway，并保留 system instruction、original task 与当前 constraints；所有外部工具经过 ToolGateway。Gateway 处理 transport retry，Agent Loop 处理 semantic repair，Checkpoint、Worker 和 Ledger 处理 recovery replay。所有受控退出都会生成完整 AgentOutcome。

## 发布前验证

```powershell
cd frontend
npm ci
npm run lint
npm test
npm run build
npm run build:showcase

cd ../backend
uv run pytest -m "not real"

cd ..
docker compose --env-file .env.docker config --quiet
```

发布前确认：

- README 中的截图和 SVG 能在 GitHub 正常显示。
- `npm run showcase` 在没有后端、没有 Key 的环境可用。
- 仓库不包含 Key、Cookie、内网地址、本地运行数据或临时计划。
- 当前工作树不再出现废弃的公开项目名。
- 展示真实联网研究前，单独验证 Provider、搜索、抓取、MySQL、Redis 和 Chroma。

更完整的阅读顺序见[源码学习指南](Agent%20Harness源码学习指南.md)。
