# 深度研究链路修复：论文获取与需求驱动阅读

## 目标与基线

题目固定为2024—2025年test-time compute scaling与数学推理，要求至少3项原始研究、模型与评测设置、计算口径、结果可比性和工程建议。采用生产装配、真实模型/搜索/抓取，20次模型调用/100000输入Token/600秒研究预算，不修改用户.env。

基线目录：`backend/runs/deep-research-20261117-baseline-4998c0`。诊断以逐次模型与工具输入输出为准，独立原论文复核不回灌给Agent。

## 已确认的架构问题

1. **来源身份与文档表示混淆。** `fetch_sources` 把arXiv摘要页当原始论文终点，即使页面正文已经提供同论文HTML全文链接也跳过。基线已获取Snell论文摘要及可观察全文链接，未继续读取全文。
2. **传输成功不等于文档可读。** HTTP抓取仅接受text/html，PDF被送入浏览器兜底后以browser_failed结束。基线的ACL论文与s1 PDF均如此；官方o1文章还触及现有HTML体积上限。不能通过重复检索修复格式能力缺失。
3. **科学阅读策略与研究需求脱节。** 科研分支忽略已经支持的read_queries，只读开头2000字符和主题匹配1000字符。全文存在的实验条件、结果与限制未必进入证据视图；父层只能看到局部窗口，补查会重新花费预算。
4. **来源准入与结论验收耦合。** 某轮 evaluator 格式失败或没有 accepted findings 时，先前获准的原文也可能失去准入状态。保留来源准入需重新核对 ACTIVE、版本与哈希，不能沿用旧 coverage 或接纳已变化的正文。
5. **任务资源没有反映论文获取过程。** 三篇目标论文只给三页抓取额度，摘要页占满名额后无法追全文。科研任务按三篇目标原文配置六页获取空间，运行级总预算保持不变。
6. **正文保真影响上层事实验证。** HTML watermark 和 PDF 旋转日期丢失，使真实年代无法通过校验。保留实际可见的时间标记，不按 URL 猜测发布日期。
7. **收尾预算只考虑写作，忽略草稿复制进核查的开销。** v3 已形成实质草稿，但剩余输入额度无法接纳独立事实核查。预算紧张的报告改用独立的聚焦原文核查，并按两次输入信封与剩余额度约束草稿长度；仍由共享 Gateway 最终准入。
8. **旧引用可能垄断独立核查窗口。** 最后完整运行发现，accepted findings 引用开头两千字符，占满核查每来源两千字符上限。为核查单独限制旧引用最多500字符，保留余量按实验字段检索；写作材料的support-first规则保持原样。补充长摘要挤占后部实验配置的失败回归，再进行真实重放。

## 方案与取舍

保留既有Controller、Tool Gateway、Evidence Store与校验契约，在获取与阅读两个边界修复：

- 论文表示解析：仅沿实际观察且已授权的链接获取同论文HTML全文；次级报道仍沿显式原文链接追踪。保持页数和重复URL上限，不能自行拼接不存在的地址。
- 格式适配：为fetch_page增加数字原生PDF文本提取，保存真实media_type、标题和页码标记；PDF失败保留明确类型，不送HTML浏览器。限制文件体积、页数及输出正文，扫描件/加密件明确失败，不把不可读PDF当研究证据。
- 需求驱动阅读：科研分支同时保留日期/摘要定位与所分配需求的定向阅读；读取查询来自需求映射/选择器，实验设置、结果和限制按实际问题取证。所有片段继续走授权、坐标、版本与全局Token预算，避免新增一层重复摘要。
- 同一需求可有多个互补阅读查询；科研片段交接按已读窗口适配，单来源最多9000字符，仍受全局 Token 装配限制。
- 核查预算不足时保留有引用草稿并明确未完成最终核查；初始生成遇到额度/传输故障时，退化为已校验的原文摘录，不把坏草稿当成事实。格式错误继续保守退化。
- 曾尝试合并写作与自检，但真实重放仍把 Snell 模型错写为 Llama，已撤销该方案。最终保留两次独立调用，不将模型自报无遗漏当作质量通过。

备选：单纯扩大来源数不能解决摘要/PDF问题；直接替换整套Agent框架无法验证哪一层改善。采用上述边界修复，复用现有执行和证据治理。

## 尚未解决的设计问题

规划器仍可能把自主选择的论文及用户未要求的参数设为硬性验收；coverage 尚未区分未读、未查到与原文明确未披露；评估器仍使用较大的整体 JSON 契约。原文坐标验证可以证明引用片段真实，不能保证模型正确理解其中的实验对象及表格行。下一层改进应围绕“模型/版本—数据集—预算—指标—条件”保存实验记录，并对重要结论逐项核对；不能只继续增加搜索与重试。
