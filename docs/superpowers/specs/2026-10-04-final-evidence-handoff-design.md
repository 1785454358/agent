## 已确认根因

上一轮真实联网主模式 F1=0.86，但为 partial/iteration_limit，三模式来源限制全部不合格。

实际轨迹重放证明：研究分支 query 已读到关键条件，评估侧 `select_read_passages` 又以通用词累加排序挑选较大的 find 窗口，挤掉关键原文。首轮评估选段与重放逐字一致。问题在已读原文交接，不是单纯研究轮数少。

另一个问题是来源约束：原始问题始终保留，但现有评估输出没有逐来源适用性判断，也没有宿主据此拒绝引用的步骤。它可能接受不属于指定版本的资料。来源正确与技术事实语义支持必须分开判断。

## 方案比较与已批准选择

1. **统一选段＋来源适用性校验（选择）**：修复已确认的重复排序，同时在原有评估调用中检查来源限制。增加少量输出字段，不增加模型调用或服务。
2. **仅统一选段**：改动较少，但不能覆盖已确认的来源验收失败。
3. **换完整研究框架或增加多层 Agent**：迁移风险和验证成本更高，不符合本轮收尾、简化和冻结目标，本轮不采用。

## 一、统一结构化选段

### 边界与数据流

`抓取正文 → 分支读取与 anchor → 共享结构选段 → 可见评估引用 → 校验后的 findings → Writer`

保留现有正文存储、来源身份、内容 hash/version、原文坐标及权限校验。在 `tools/evidence_views.py` 的既有结构选段中增加有界的已读范围输入，或抽取其内部纯函数供两个入口共同使用；不得复制第二套词频排序。`evidence_units.py` 只负责校验 anchor、保护已接受的支持和生成短引用单位，不再独立决定通用词相关性。

### 选择规则

- 优先保留当前版本中已接受、原文字面匹配的支持片段。
- 已存在合法 anchor 时，仅在其实际可见范围的并集中选材；不从未读正文借用条件、标题或引用，不拼接后制造新坐标。
- 合法已读内容能完整放入预算时保留全文，不能因词面不匹配丢掉明确读过的短片段。
- 已读内容超预算时使用共享实体、标题/节、长度归一与固定需求轮转规则，保留完整可见组及条件、否定和例外；不可分割的超限组省略并诊断，不取前缀冒充完整条件。
- 原有无有效 anchor 的授权正文取材兼容路径不扩大范围；失效或伪造 anchor 仍拒绝。不能将该路径建立为分支已读证明。
- 评估侧总 JSON 预算仍完整组进出。组的优先级不得再被“原文较靠前”覆盖，避免在第二次序列化预算分配时重现关键组丢失。
- 词面命中只决定取材，不自动将 requirement 标为 covered；候选研究员主张不参与语义充分性证明。

### 预算

继续使用既有 read、单来源评估 3000 原文字符、全局 token 和引用单位上限。标签/JSON 开销照实计入原有可见性预算；每个可见 ref 必须对应本次实际展示的原文。不得为了放入更多材料扩大预算。

## 二、同一评估调用检查来源适用性

### 输入和输出

保留完整原始问题为权威用户要求；不把 planner 的字符串元数据提升为工具权限，不新增域名访问权。

在三模式的实时 Reference 评估 DTO 中共用一个有界来源检查 DTO。来源检查引用本次 `sources` 的短编号 `s1...s8`，状态为 `eligible / ineligible / uncertain`，并给出有界理由。只判断当前用户明确的资料来源、官方身份和版本等限制，不自行增加新要求。无相关限制时不额外排除合法来源。

评估模型在现有一次调用中同时输出来源适用性、原文 findings 和需求覆盖。判断依赖实际 requested/final/canonical 来源身份和可见原文；URL/标题不能作为技术结论的事实证据。来源编号合法也不等于来源语义合格。

### 宿主校验与降级

- 核验来源编号来自本次可见来源表；未知、重复、遗漏或无可见原文的来源不能默认 eligible。
- `ineligible`、`uncertain` 或检查无效的来源不能支持可接受 findings。混合来源 finding 若包含被拒绝的支持，整条拒绝，不能去掉不利支持后继续声称原结论已被证明。
- 来源检查缺失时安全降级，保留诊断与未完成需求，不视为空限制或自动通过。历史 DTO 仍可解码；历史输出没有来源检查，不直接获得新的完成资格。
- 用过滤后的 findings 重新归一 coverage；没有有效 finding 支持的 covered 降为 missing。沿用现有补查路由、调用计量和完成门禁。
- 不合格来源不进入最终答案引用；Writer 的已有分支回退资料路径也必须遵守同一来源检查结果，不能绕过评估过滤重新引入旧版本 URL。
- 模型判断适用性不构成确定性正确证明；真实测试另做严格来源审计。如果模型误判，仍计验收失败，不掩盖该边界。
