# Global Support Budget：必要原文优先的共享预算

## 目标与已确认范围

用户已同意先重构共享支持预算，再独立处理相关性取材。此轮消除“必要引用本能放下，却被前面引用的上下文边距挤掉”和“重叠引用重复计费”的问题。只改变确定性的原文范围分配，不改变需求、模型语义判断或完成标准。

推荐必要原文全局合并后再加上下文，而非增加预算或同时重排读取锚点。两种替代方案分别不能修正分配错误、难以分离效果。本规格不保证补齐缺少的恢复操作细节，不承诺提高真实F1或解决MA的无关前言取材。

## 已复现根因

对上一批多跳P&E实际评估输入、短引用和可见坐标复原全部EvidenceSupport，逐项通过现有support_matches_record：六个唯一单位的必要原文并集为2445字符（48500:50589、50904:51260），小于3000。旧supported_ranges最终选择2714字符，却缺少finding-5的完整支持；Writer据此正确输出response_evidence_context_limit/partial。

旧算法逐条保留quote并立即加最多120字符边距。后面的quote按总长度与remaining比较，而不是按合并后的新增字符比较，既让非必要边距先占额度，又误拒绝仅新增少量字符的重叠引用。

通用只读复现（不依赖gold或特定主题）：

- 800额度，原文支持100:500及1000:1400，并集恰为800；旧算法只保留第一条。
- 700额度，原文支持100:500及400:650，并集550；旧算法仍丢第二条，尽管其相对已选范围只新增30字符。

## 共享算法与接口

保留tools/evidence_views.py的supported_ranges(record, body, supports, limit) -> list[tuple[int, int]]签名。它仍是select_supported_passages（Writer/历史兼容视图）和select_read_passages（v3评估材料）的唯一支持范围入口。实现可用小型私有纯函数分离并集成本和上下文扩展，不新增通用服务、状态或分配器框架。

### 阶段一：必要原文

1. limit必须为严格正整数，True、浮点、零及负值拒绝；保持现有调用者参数规则。
2. 只接受现有support_matches_record通过的支持：来源、版本、哈希、严格坐标、原文逐字一致、quote长度1至500均不放宽。按首次出现的坐标去重；正文与支持对象不修改。
3. 全部合法支持先合并重叠/相邻范围，以并集长度计费。若并集不超过limit，必须完整保留全部合法支持，结果不因支持输入顺序不同而缺失。
4. 若全部必要原文本身超限，按合法支持的首次输入顺序尝试完整quote；每次合并候选并计算实际并集长度，能容纳才加入，不能容纳则跳过后继续尝试其他支持。不能截断quote、超预算或根据测试题/gold选择优先级。这不是全局最优背包或语义排序。

### 阶段二：可选上下文

必要原文选择封存后才允许扩展上下文，不能撤销或截断已选必要范围。按阶段一合并范围的正文坐标顺序尝试扩展：每边最多120原始字符，以同一对称margin扩展并在正文边界裁剪；选择0至120内、合并后总长度仍不超过limit的最大margin。后续区间使用当前已选并集计算新增成本，重叠与相邻内容不重复计费。

正文不相邻的范围不拼接成一条原文quote；输出仍为排序、互不重叠的原始坐标列表。上下文可因剩余预算有限而不对称（正文边界裁剪），或完全没有。最后剩余空间由已有查询选段/读取锚点流程处理，不改变其排序与回退。

“每来源3000”仍只计算原始正文字符，范围标签/JSON开销仍受既有整体token预算另行约束。本修复不保证来源上限、128引用单位或token掉落后全部支持仍可见。

## 失败、安全与兼容

- 真正超出必要原文字额时允许部分支持未被选择；只有最终实际可见、完整且已校验的支持能供Writer/coverage使用。上下文恰好使此前跳过的quote完整可见时，仍按现有最终可见性校验判断，不把“阶段一跳过”强行变成失败或成功。
- Writer的visible_findings、response_evidence_context_limit、partial与引用门禁保持不变；本轮修的是材料分配，不修改这些门禁来宣称完成。整体token不足时继续如实partial。
- 沿用既有读取/材料丢弃诊断与Writer限制说明，不新增公共API字段或全局错误服务。非法支持忽略，不能取得隐含授权；来源读取的租户、ACTIVE生命周期与权限仍由当前边界执行。
- 契约v3和历史完成v2消费者继续兼容；不升级schema、持久化算法或checkpoint结构，不打开旧中途状态派发权限。既有原文位置/哈希身份不变，变化的可见材料体现在新实验身份中。
- 不改变读取锚点的首次顺序、相关性排序、抓取范围、记忆准入、三模式调度、模型/提示、修复尝试次数、总预算、评分器、gold或旧批结果。
